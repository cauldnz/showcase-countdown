showcase-countdown

An NTP-synchronised event countdown for the M5StickC PLUS SE. Plug your Stick in over USB and install it directly from this page.

This browser cannot talk to serial devices. Open this page in Chrome, Edge, or Opera on a desktop computer. Installing requires a secure (https) connection.

Before you start

  • Use Chrome, Edge, or Opera on a desktop. Safari and mobile browsers cannot access serial ports.
  • On Windows, install the FTDI VCP driver first. The PLUS SE will not appear as a COM port without it, and some machines need it installed twice.
  • Close any other program using the port, including the Arduino IDE or a PlatformIO serial monitor.

What happens

  1. Pick your Stick's serial port when the browser asks.
  2. The firmware is written, which takes about a minute.
  3. You are prompted for your Wi-Fi network. Credentials are sent over the USB cable and saved on the device.
  4. The Stick syncs its clock from NTP and starts counting down.
Your Wi-Fi credentials are never part of the download. The published firmware contains no network details at all: it asks for them after installing and stores them on the device, so this page cannot see them and neither can anyone else who downloads the image.

Afterwards

The Stick has a few controls once it is running:

  • Single-click button A to force a clock re-sync, double-click to toggle the Grove lights.
  • Button B shows the diagnostics screen.
  • Over serial at 115200 baud, send ? for the full command list.

To move the device to a different network, run the installer again and choose the Wi-Fi option, or send w over serial to forget the stored credentials.
